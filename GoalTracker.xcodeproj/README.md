# HabitSpark - 振り返りで続く、シンプル習慣化アプリ

KPT法（Keep/Problem/Try）を取り入れ、ただ記録するだけでなく「なぜ続かなかったのか」「次はどうするか」をセットで管理できる習慣化・目標管理アプリです。

## 🚀 特徴
- **KPTベースの振り返り**: 週末や月末に自分と向き合う時間を。
- **ヒートマップ & カレンダー**: 進捗を視覚的に確認し、モチベーションを維持。
- **ウィジェット対応**: ホーム画面から今日のタスクを素早くチェック。
- **動的な通知**: 設定した目標に合わせて、ランダムにリマインド。

## 🛠 技術スタック
- **Language**: Swift 5.x
- **UI Framework**: SwiftUI
- **Database**: CoreData (App Groups による Widget 共有)
- **Ads**: Google Mobile Ads SDK (AdMob)
- **Architecture**: MVVM

## 📂 開発の背景
「チュートリアルは終わったけれど、実際にどうやって一つのアプリをリリースまで持っていくのか？」という課題に対し、設計の分離（Fat Viewの脱却）やデータの永続化など、実戦的な技術を盛り込んで開発しました。
